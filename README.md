# Reputation House — сайт на Nuxt

Страницы по визуальному образцу https://reputation.house/ на Nuxt 4 и Vue 3 с SSR.

Реализованы `/`, `/solutions`, `/reputation-management-pricing`, `/faq` и `/contacts`. Каталог содержит 22 услуги, FAQ — 41 ответ в восьми категориях. Ссылки на реализованные страницы автоматически направляются на локальные маршруты через `SiteLink`.

## Запуск

Требуется Node.js 22.19+.

```sh
npm install
npm run dev
```

Локальный адрес: http://127.0.0.1:3000/.

```sh
npm run typecheck
npm run format:check
npm run build
npm run preview -- --port 3001
```

## Структура

- `app/components/HomePage.vue` собирает главную из отдельных секций.
- `app/pages` содержит самостоятельные страницы с метаданными и Nuxt-маршрутами.
- `HeroSection.vue`, `ServicesSection.vue`, `CaseStudies.vue` и остальные секции содержат читаемые Vue-шаблоны и локальные стили.
- `ContentCarousel.vue`, `ActionButton.vue` и `SectionHeading.vue` — переиспользуемые компоненты.
- `SiteHeader.vue`, `FaqAccordion.vue`, `ConsultationModal.vue` управляют интерактивностью через Vue.
- `app/data` содержит структурированный контент без HTML.
- `app/assets/main.css` содержит общие стили и дизайн-переменные.
- `public/images` и `public/fonts` содержат локальные изображения и шрифты.

Адаптивная раскладка реализована на CSS Grid и Flexbox. В приложении нет экспортированной разметки, технических ID, стилей или runtime Tilda. Декоративная схема первого экрана на узких экранах превращается в горизонтальный список карточек, как на оригинале.

`scripts/inspect-reference.mjs` и `scripts/build-content.mjs` использовались для переноса контента в JSON; для запуска сайта они не нужны. Загруженные исходники в `scripts/reference` исключены из Git и не попадают в приложение.

После запуска production-предпросмотра `node scripts/verify-site.mjs` проверяет маршруты, заголовки, локальные ссылки и доступность ресурсов.

## Границы реализации

Страницы отдельных услуг, компании, кейсов, новостей и другие ещё не перенесённые разделы открываются на оригинальном сайте. Формы демонстрационные: проверяют заполнение и показывают результат, но не сохраняют и не отправляют данные. Аналитика и сторонние обработчики форм не подключены.
